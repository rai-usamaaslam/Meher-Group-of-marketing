# Image placeholders

The landing page uses clearly identified Unsplash architecture and portrait placeholders in the EJS partials and route data. They are external development placeholders, not MGM photography. Replace each `images.unsplash.com` URL with the matching approved local asset when available; the image `alt` text and project/team content are already separated from layout markup.

Suggested local asset groups: `hero/`, `about/`, `services/`, `projects/`, `team/`, and `gallery/`.
